Password-Generator

This python code generates random 16 character password for your personal, school, or work accounts

Requires
Following are the requirements to run the code:
Python 

How to run the script:
- Clone repo to your local machine using download zip or git with the following command: git clone https://github.com/RoshanC99/password-generator.git
- Run the password_generator.py either through your preferred IDE or Terminal with the following command: python3 password_generator.py
